# krinmed-media
Images for the Krinmed (@krin.med) Instagram page, published via Metricool.

- `brand/logos/` — Krinmed logo, EEP logo, phoenix watermark
- `brand/products/` — product photos (add new ones here)
- `brand/render.py` — slide template renderer
- `posts/<date>-<topic>/` — slides of each post (JPEG = what was sent to Instagram)
